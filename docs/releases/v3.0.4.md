Playtime Tracker 3.0.4 does less work in the background, so it's lighter on your PC while you play.

**Download:** `Setup.exe` below. If you have 3.0.3, 3.0.2, 3.0.1, 3.0.0 or 2.2.0, it updates itself when no game is running.

## Improved
- **Lighter dashboard while you play.** While a game was running, the dashboard reloaded your whole play history every second to count up the time, on every page and even when minimized. It now only does that while the Overview page or a dialog shows the running time, and never while minimized.
- **Lighter tracker.** Checking for running games copies less data on each check, the tray tooltip is only updated when it changes, and less memory is used for each program that starts.
