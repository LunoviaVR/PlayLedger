Playtime Tracker 3.0.0 is rebuilt from the ground up in Rust, with a new Windows 11 dashboard: faster, lighter, and with no extra runtime to install. Your history and settings carry over unchanged.

**Download:** `Setup.exe` below. Double-click it and follow the steps; no admin rights needed. If you have 2.2.0, it updates itself when no game is running.

## A new dashboard
- **Windows 11 style, like Task Manager:** a navigation pane on the left (Overview, Games, History, Statistics, Settings) that folds to icons, with cards throughout.
- **Glass look:** Windows' own Mica material shows your wallpaper's colour behind the window, with see-through cards. It switches to solid colours when Windows' transparency effects are off, with a high-contrast theme, or when you turn off **Settings → Appearance → Glass effects**.
- **Your accent colour everywhere:** buttons, switches, selection and charts all follow **Settings → Appearance → Accent colour**.
- **Fits any window size:** tiles reflow from four across to one per row, History and Statistics never squeeze text into one letter per line, and the window keeps a sensible minimum size.
- **Hardware acceleration:** on by default. If the window flickers or stays blank (for example over remote desktop), turn it off in **Settings → Appearance** and click **Reopen now**. If the graphics card can't draw it, the dashboard switches to drawing without it on its own.
- **Screen readers and keyboard** work throughout.

## Games page
- **Right-click a game** (or press the Menu key, Shift+F10, or press and hold) for:
  - **Change artwork ▸ Choose an image file…**: your own picture, **600 × 900** (2:3) works best. PNG with transparency, JPEG and WebP all work.
  - **Change artwork ▸ Pick from SteamGridDB…**: choose from SteamGridDB's pictures for the game (needs **Download missing artwork** on and your own free key).
  - **Change artwork ▸ Use automatic artwork**, **Stop tracking** and **Delete history…**
- Box art or icons on every tile, with search and sort, and what's playing first.

## Settings
- **Search** in Ignored Games and Ignored Programs, with a count ("3 of 41").
- **Get API key** next to the SteamGridDB key box, while no key is saved.
- **Your Data** now sits right below Game Folders, and section headings are in title case.
- **Support Playtime Tracker**: a **Tip or Donate** button below About, if you'd like to support the project.

## Fixed
- Running sessions count up every second again.
- A single game's sessions on the Overview show the game's name.
- Pages fill the window when it's resized or maximised.
- Starting the dashboard right after closing it always opens a window.

## Upgrading
- **2.2.0 updates itself** to 3.0.0 when no game is running, or run `Setup.exe` over it. Earlier versions: run `Setup.exe` once.
- **Your history, settings and "start with Windows" choice are kept.** Before 3.0.0 first runs, it backs them up to `Documents\Playtime Tracker\Backups`.
- The download is smaller and nothing else is installed with it.
