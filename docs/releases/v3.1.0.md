Playtime Tracker is now **PlayLedger**, with a new name, logo and icon.

**Download:** `Setup.exe` below. If you have Playtime Tracker 3.0.4 or earlier (back to 2.2.0), it updates itself when no game is running, and becomes PlayLedger.

## New
- **A new name and look.** The app, its window, the tray, notifications, the installer, the Start menu shortcut and the Apps list now say **PlayLedger**, with the new blue book-and-controller icon.

## Nothing to do
- **Your history and settings are kept.** Updating changes only the name you see. Your play history, settings, artwork and "Start with Windows" choice stay exactly where they were, so some folders (such as `Documents\Playtime Tracker`) keep their old name.
- **Shortcuts are renamed for you.** The Start menu shortcut becomes **PlayLedger**, and a desktop shortcut, if you have one, is renamed too.
