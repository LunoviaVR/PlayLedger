Playtime Tracker 3.0.2 replaces the glass look with an AMOLED mode that has true blacks.

**Download:** `Setup.exe` below. If you have 3.0.1, 3.0.0 or 2.2.0, it updates itself when no game is running.

## New
- **AMOLED mode.** Turn it on in **Settings → Appearance** to give the dark theme true black behind everything, with cards just above it. It looks deeper, and on an OLED screen the black pixels are switched off, which saves power. The title bar turns black to match. It's off by default and has no effect in the light theme.

## Removed
- **Glass effects.** On some PCs, depending on the graphics card and its driver, the see-through glass look drew the window black instead. The dashboard now always uses solid colours, which look the same on every PC.
